# SeekaNepal

**Learn. Ask. Understand.** A Nepal-focused AI learning platform MVP for students from Class 1 to 12.

Founded and built by **Riyaz Chalise**.

## Included in this deployable project

- Next.js App Router + TypeScript
- Responsive landing page and navigation
- Class hubs for Classes 1–12
- Mathematics, Science, English, Nepali, Social Studies, Computer Science, and Optional Mathematics
- Dynamic class/subject routes with route-specific metadata
- AI Tutor, Practice, Progress, About, and FAQ MVP pages
- Sample topic pages for Force and Motion and Fractions
- Favicon, social preview, manifest, Open Graph, Twitter metadata, JSON-LD
- Vercel-based `robots.txt` and `sitemap.xml`
- `SEO-CONFIGURATION.md` with deployment and content guidance

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for Vercel

```bash
npm run build
npm start
```

Import this repository into Vercel or deploy with the Vercel CLI. The canonical origin in metadata is currently `https://seekanepal.vercel.app`; update it if Vercel assigns a different project URL.

## Important product note

Demo educational content is labeled. Do not claim official Nepal curriculum alignment until the relevant curriculum data is verified and implemented. Private dashboards, accounts, and tutor sessions should remain behind authentication when backend services are added.
