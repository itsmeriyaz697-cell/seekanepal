# SeekaNepal Deployment Package

Verified deployment source for SeekaNepal, founded and built by Riyaz Chalise.

## Deploy

```bash
npm install
npm run build
npm start
```

For Vercel, import this folder/repository. The current canonical URL in metadata is `https://seekanepal.vercel.app`; update it if the assigned Vercel URL is different.

## Included

- Next.js App Router + TypeScript
- Classes 1–12
- Mathematics, Science, English, Nepali, Social Studies, Computer Science, Optional Mathematics
- Core learning, tutor, practice, progress, About and FAQ routes
- Class, subject and topic routes with SEO-friendly `/class-N/...` middleware rewrites
- Favicon, Open Graph image, web manifest, robots and sitemap
- JSON-LD organization, founder and website metadata
- SEO configuration and deployment README
